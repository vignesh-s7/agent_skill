# UI/UX Pro Max

**Role:** Design Intelligence & Interface Architecture  
**Origin:** https://github.com/nextlevelbuilder/ui-ux-pro-max-skill  
**License:** MIT License  

## Summary
A comprehensive design intelligence skill packaging deterministic UI/UX best practices, typography scales, accessibility contrasts (WCAG 2.1 AA), and clean interface design tokens for modern web and mobile applications.

## Core Design Principles
1. **Hierarchy First**: Structure interfaces with distinct typographic scale (H1: 32px/2rem, H2: 24px/1.5rem, Body: 16px/1rem).
2. **Accessible Contrast**: Ensure all text elements meet minimum 4.5:1 contrast against their backgrounds.
3. **Spacing Discipline**: Enforce consistent 8-point grid rhythm (4px, 8px, 16px, 24px, 32px, 48px, 64px).
4. **State Coverage**: Every interactive element must define all 5 states: default, hover, active/pressed, focus-visible, and disabled.
5. **Modern Neutral Palettes**: High-contrast, dark-mode ready tokens with semantic accents (success: emerald, warning: amber, danger: rose, info: sky).
